# VaultDocs

A secure, cloud-native document management platform built with Rust, Leptos, and AWS.

VaultDocs allows users to securely upload, organise, and search their documents through a modern web interface. Files are stored using encrypted object storage, with per-file encryption keys and AI-powered semantic search capabilities.

The goal of VaultDocs is to provide a privacy-focused alternative to traditional cloud storage platforms while demonstrating modern backend architecture, cloud infrastructure, and secure application design.
